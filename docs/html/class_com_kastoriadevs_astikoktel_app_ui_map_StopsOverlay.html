Detailed Description

private class StopsOverlay(
    density: Float,
    private val pin: Bitmap,
    private val openPin: Bitmap,
    private val onTap: (String) -> Unit,
) : Overlay()

All the stops in one overlay: pins from street level up, small dots further out where 209 pins would cover the map. The open stop always gets its big pin, drawn last so it sits on top.
