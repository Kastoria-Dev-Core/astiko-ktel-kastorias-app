private enum class Tab(
    @StringRes val label: Int,
    val route: Any,
    val isRoot: (NavDestination) -> Boolean,

Bottom tabs. Screens opened from a tab stay part of it, so the highlighted tab is tracked from the back stack rather than from the screen shown: a map opened with "Show on map" from a stop still belongs to Home.
