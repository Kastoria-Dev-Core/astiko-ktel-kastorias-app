Detailed Description

class Announcer(
    context: Context,
    private val locale: Locale,
    private val onLanguageMissing: () -> Unit,
)

Reads text out loud with the phone's own text-to-speech engine, in the app's language. The engine starts in the background; whatever is asked before it's ready is said once it is.
